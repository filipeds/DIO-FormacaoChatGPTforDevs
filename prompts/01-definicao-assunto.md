# 01 — Definição do assunto

- **Ferramenta:** Claude Code (Claude Opus 5, Anthropic)
- **Etapa:** delimitação do tema antes da montagem do repositório

## Prompt utilizado

Trecho do prompt enviado ao Claude Code, onde o assunto do artigo foi definido:

```text
Estou no repositório já existente, na branch "feat/artigos-tecnicos-chatgpt-lexica",
trabalhando no desafio de projeto da DIO "Gerando Artigos com Inteligência Artificial".

(...)

4. Atualize (ou crie, se não existir) o README.md na raiz do repositório contendo:
   - Título do projeto e breve descrição do desafio (bootcamp DIO)
   - Seção "Sobre o artigo": tema é "Claude e o uso de IA na geração de código e
     como acelerador de desenvolvedores"
```

## Resultado obtido

O tema foi definido diretamente no prompt, sem etapa de brainstorming com a IA — o
recorte já estava decidido antes de acionar o Claude Code.

- **Tema:** Claude e o uso de IA na geração de código e como acelerador de desenvolvedores
- **Público-alvo:** desenvolvedores construindo portfólio e times avaliando ferramentas de IA
- **Ângulo escolhido:** a diferença entre "IA que sugere" e "IA que executa" — do chat
  ao agente que lê o repositório, edita arquivos e roda comandos

## Observações

O texto completo do artigo já chegou pronto dentro do prompt (delimitado por
`--- INÍCIO DO CONTEÚDO DO ARTIGO ---` / `--- FIM DO CONTEÚDO DO ARTIGO ---`),
portanto o Claude Code atuou a partir da estrutura do repositório, e não na redação
do texto. Se o rascunho foi escrito antes em outra ferramenta, registre aqui qual foi.
