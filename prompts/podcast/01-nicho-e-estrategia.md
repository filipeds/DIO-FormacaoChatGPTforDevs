# 01 — Nicho e estratégia de posicionamento

- **Ferramenta:** Claude Code (Claude Opus 5, Anthropic)
- **Etapa:** decisão do nicho, antes de qualquer prompt de conteúdo

## Contexto

A primeira aula do módulo é categórica: *"fazer um podcast sem estratégia é
basicamente hobby"*. Antes de pedir nome ou roteiro para a IA, é preciso decidir o
nicho e o subnicho — aquilo pelo qual você quer ser reconhecido no mercado.

O expert usa o exemplo dele: nicho de tecnologia, subnicho de JavaScript, porque é
como ele quer se posicionar. A pergunta que a aula deixa é *"e o seu?"*.

## Prompt utilizado

```text
Estou no desafio da DIO "Criando um Podcast com Inteligência Artificial", na
branch feat/podcast-ias-generativas.

Este repositório já tem dois desafios entregues sobre o mesmo recorte:
- um artigo sobre Claude e IA como aceleradora de desenvolvedores
- um e-book, "O Dev Aumentado", sobre IA agêntica na geração de código

Considerando que a primeira aula do módulo defende escolher um subnicho de
posicionamento e produzir consistentemente dentro dele, avalie: qual subnicho o
podcast deve ocupar para que os três desafios somem autoridade em vez de virarem
três trabalhos avulsos?

Não proponha um tema só porque é popular. Justifique pela coerência com o que já
está publicado no repositório.
```

## Resultado obtido

- **Nicho:** tecnologia
- **Subnicho:** IA agêntica no dia a dia de quem programa
- **Público-alvo:** pessoas desenvolvedoras que já usam IA para completar código e
  querem entender o que muda quando ela passa a executar

A recomendação foi manter o mesmo recorte do artigo e do e-book. O argumento: um
portfólio com três peças sobre o mesmo assunto lê como especialização; três peças
sobre assuntos diferentes leem como exercícios de curso. É exatamente o raciocínio
que a aula aplica ao caso do profissional Java que não deveria produzir conteúdo
de .NET.

## Observações

Esta etapa não existe no repositório do expert como um prompt — ela é conversa de
aula. Documentei como prompt porque a decisão de nicho é a que condiciona todas as
seguintes: o nome, os blocos do roteiro e até o tom da narração saem daqui.

O contraponto honesto: escolher o mesmo tema dos outros dois desafios é confortável
e pode parecer preguiça de pauta. A defesa é que profundidade em um recorte vale
mais para uma entrevista técnica do que variedade rasa — mas quem for replicar
deve escolher o *seu* subnicho, não copiar este.
